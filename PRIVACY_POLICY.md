# Privacy Policy for SenseUI Chrome Extension

Last updated: March 20, 2026

SenseUI is a Chrome extension that provides AI-assisted visual design feedback for blind and low-vision web developers.

## Summary

- We do not sell personal data.
- We do not use your data for advertising.
- We do not intentionally collect sensitive personal data.
- Data is processed only to provide the extension features you request.

## Data We Access and Process

SenseUI may process the following data when you use the extension:

- Webpage code and structure from the active tab (such as HTML and CSS) when you request analysis.
- A screenshot of the active webpage when you request analysis.
- Prompts and chat content you enter in the extension.
- Extension settings you save (for example, preferences and configuration values).

## Why We Process This Data

We process data only to:

- Generate visual descriptions and design feedback.
- Support extension functionality and user settings.
- Improve reliability and fix issues.

## Chrome Permissions and Their Purpose

SenseUI requests the following permissions:

- `activeTab`: Access the currently active tab only when needed for requested analysis.
- `tabs`: Read tab information needed to operate the extension panel and analysis flow.
- `scripting`: Run scripts required to collect page context for analysis.
- `storage`: Save extension preferences and local settings.
- `sidePanel`: Provide the extension interface in Chrome side panel mode.
- `host_permissions` (`<all_urls>`): Allow analysis on websites where you choose to use SenseUI.

## Data Sharing and Third Parties

To provide AI feedback, SenseUI may send relevant page context (such as HTML/CSS, screenshot, and your prompt) to a third-party AI API provider selected by the user or configured by the extension.

- Data sent to the AI provider is used to generate responses.
- We do not authorize third parties to use your data for advertising.
- AI provider retention and processing may be governed by that provider's own policy.

Do not submit confidential, proprietary, or sensitive information through SenseUI.

## Data Storage and Retention

- Settings and configuration are stored using Chrome extension storage.
- Chat or analysis data is retained only as needed for feature functionality and troubleshooting.
- You can clear extension data by removing the extension and clearing its storage.

## Children

SenseUI is not directed to children under 13, and we do not knowingly collect personal information from children.

## International Users

If data is processed by third-party AI providers, it may be processed in countries outside your own jurisdiction.

## Security

We apply reasonable technical and organizational measures to protect data. No method of transmission or storage is 100% secure.

## Your Choices

- You can choose when to run analysis.
- You can avoid sharing sensitive data.
- You can uninstall the extension at any time.

## Changes to This Policy

We may update this Privacy Policy from time to time. Updates will be posted at this URL with a revised date.
